## Summary

The Main board's composer lists what a message carries as chips above its text and switches
between Plan and Act with a two-segment control; Marley shows @-mentions only as creases inside
the text and keeps Zed's mode dropdown. The board's details panel puts each section in a card,
says under the agent what it is doing now, shows the thread's folder and mode as two tiles, and
offers "Open in a tab" under the terminal peek; Marley's panel has flat sections, the agent's
name and model only, and no link. This ticket draws the composer's chips and switch and the
panel as the board does.

## Acceptance

A draft's mentions show as chips above its text; an agent with a plan mode gets Plan / Act; the
details panel's sections are cards, with the agent's state line, Folder and Mode tiles, and Open
in a tab under the terminal peek; shot in Marley Night and Marley Day.
